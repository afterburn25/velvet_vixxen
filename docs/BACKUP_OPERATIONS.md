# Backup and recovery operations guide

The canonical operator guide is [app/Docs/BACKUP_OPERATIONS.md](../app/Docs/BACKUP_OPERATIONS.md).
It is included in Fresh and Upgrade runtime packages and is available to the
current owner from the Operations page. Keeping one copy ensures that the
reviewed CLI setup, host prerequisites, retention limits, complete restore drill
and quarantined activation instructions match the shipped implementation.
