# Add-on SDK

The included `velvet-welcome-banner` source and ZIP are the supported 0.6.0 starter. It demonstrates permissions, admin pages, public routes, homepage widgets, namespaced settings, core events, services, scheduled tasks, checksums, installation, deactivation, Safe Mode, backups, rollback, and uninstall.

Read `docs/ADDON-DEVELOPMENT.md` or download the guide from **Admin → Add-ons → Developer SDK**.
